# Metro Founder — Isometric City Builder

A playable original browser city-builder with mobile touch controls.

## Features
- Required local player registration and login (player name, email, password)
- Isometric-style map, road placement, zoning, building upgrades, parks and bulldozing
- Moving traffic/pedestrians, railway tracks, train visuals, water tiles and boats
- Railway stations, schools, career missions, tax income, population and happiness
- Pan, pinch zoom, local save/load

## Publish using iPhone and GitHub Pages
1. Extract this ZIP in the Files app.
2. Create a GitHub repository, e.g. `metro-founder`.
3. Upload `index.html` and `README.md` to the repository root and commit.
4. Open Settings → Pages.
5. Select Deploy from a branch, branch `main`, folder `/(root)`, then Save.
6. Open `https://YOUR-USERNAME.github.io/metro-founder/` after deployment.

## Important account limitation
Registration is local to the browser/device. It is not a secure server-backed account, email is not verified, and accounts/game saves do not sync between devices. Do not reuse an important password. A real public multiplayer/login system requires a backend and secure authentication service.

Game saves are stored in local browser storage. This is an original lightweight game, not a full Cities: Skylines simulation; vehicle and transport movement is visual, with complex route-finding and service simulation planned for future upgrades.
