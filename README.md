# Metro Founder
A mobile-friendly, original isometric-style city-building career game made with HTML Canvas and vanilla JavaScript.

## Publish with GitHub Pages using iPhone
1. Create a GitHub repository named `metro-founder`.
2. Open it and choose **Add file → Upload files**.
3. Upload `index.html` and `README.md` from this folder and commit.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
6. After deployment, open `https://YOUR-USERNAME.github.io/metro-founder/`.

## Controls
- Road: tap or drag to build roads.
- Residential/commercial/industry: build next to roads.
- Park: improves happiness.
- Inspect: tap buildings to upgrade; drag empty land to pan.
- Pinch or use zoom buttons to zoom.
- Missions: claim rewards.
- Save/Load: local browser storage on this device.

## Notes
- Original game, inspired by the city-building genre; not a clone.
- Simplified career economy: tax income arrives every 15 real seconds (one game day).
- Saves are local to the browser/device.
- No paid services or API keys required.
